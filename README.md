# Ghar Ka Zaika by Areeba — Rice Menu (PWA Web App)

Is ZIP folder mein complete multi-file website aur PWA (Home Screen Shortcut / Offline App) setup shaamil hai:

- `index.html` — Main menu structure aur layout
- `style.css` — Complete brown, cream & gold styling aur responsive mobile design
- `app.js` — All 10 dishes, quantity counter, WhatsApp order builder (`03142011627`), aur Add Shortcut logic
- `manifest.json` — Home Screen Shortcut / Installable App configuration
- `sw.js` — Offline caching service worker
- `icon.svg` — App shortcut icon
- `README.md` — Setup guide

## GitHub Pages par Publish karne ka tareeqa:
1. Is ZIP file ko extract (unzip) karein.
2. GitHub par apni Public repository mein saari **7 files** upload karein.
3. **Settings > Pages** mein ja kar Branch `main` select karke **Save** karein.
4. Live link khol kar upar **"📲 Add Shortcut"** button dabane se yeh phone ki home screen par app shortcut ban kar save ho jayega!
